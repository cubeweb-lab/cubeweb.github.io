🚀 CubeOS — 64-битная ОС с нуля

CubeOS — учебная 64-битная операционная система: собственный загрузчик, переход в Long Mode, страничная адресация, обработка прерываний, драйвер ATA PIO, файловая система FAT32 и пользовательские программы в Ring 3. Ядро написано на Rust (no_std), загрузчик — на NASM.

📋 Системные требования

  • Процессор: x86_64 с поддержкой Long Mode
  • Память: 32 МБ (минимум), рекомендуется 128 МБ
  • Диск: 20 МБ (образ с FAT32-разделом)
  • Платформа: QEMU (протестировано), Bochs, VirtualBox
  • Загрузчик: Multiboot2 (GRUB / QEMU -kernel)

🖥️ Shell (/bin/csh)

Интерактивный шелл запускается как ELF-программа в Ring 3 и общается с ядром через syscall.

ls [path] — список файлов и каталогов
cd [path] — сменить текущий каталог
pwd — показать текущий путь
cat <file> — вывести содержимое файла
mkdir <path> — создать каталог
rm <path> — удалить файл
echo <text> — вывести текст
help — справка
exit — выход (возврат в ядро)

🧩 Стек технологий

  • Ядро: Rust (no_std, nightly, build-std)
  • Загрузчик: NASM, Multiboot2
  • Целевая архитектура: x86_64, Long Mode, identity paging 0..4 ГБ
  • Драйверы: ATA PIO, COM1, VGA-текст, VESA framebuffer
  • ФС: FAT32 (чтение/запись, 8.3, LFN-записи пока только читаются)
  • ABI: System V AMD64 для syscall (rax=num, rdi/rsi/rdx/r10/r8/r9=args, rax=ret)
  • Сборка: Makefile, cargo +nightly build -Z build-std=core,compiler_builtins

📥 Сборка и запуск

# 1. Собрать ядро
make -j4

# 2. Собрать шелл (/bin/csh)
make csh -j4

# 3. Собрать образ с FAT32 и положить csh в /bin/csh
make image

# 4. Запустить в QEMU
qemu-system-x86_64 -drive format=raw,file=cubeos.img -m 128M -serial stdio

# С отладкой исключений (полезно при разработке)
qemu-system-x86_64 -drive format=raw,file=cubeos.img -m 128M \
-serial stdio -no-reboot -no-shutdown -d int,cpu_reset
